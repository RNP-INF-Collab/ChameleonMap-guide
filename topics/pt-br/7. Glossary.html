Glossário

1) Tag:

Um information unit. Em o admin interface it é possible para add ou edit tags, which one having um set de particular informations. Tags são grouped em tag menus e pode ser binded para locais. O same tag pode ser binded para multiples locais.

2) Local:

Um specific geographic local em o global mapa, consisting de um latitude e um longitude. Locais pode ser added via o admin interface. It é possible para bind tags para each local, as many tags as desired.

3) Link:

Um connection between two locais.

4) Tags Menu:

Um palette de registered tags. Um mapa instance pode have many tags menus.

5) Links Menu:

Um unique menu de links, que pode ser deactivated via admin interface.

6) ATLAS:

Acronym para Automated Topology Idioma com Slices, which é um topology representation idioma. Em este context, ATLAS also refers para um representation sistema based em ATLAS idioma. O ChamaleonMap has um embedded ATLAS generator tool.
