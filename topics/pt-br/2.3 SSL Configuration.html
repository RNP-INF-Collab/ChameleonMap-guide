Configuração SSL

Para apply SSL para o inventory mapa, it é necessary para modify some NGINX settings para adapt para your site.

  1. Change o site nome em o nginx_ssl/nginx.conf file:

    Replace

    server {
    listen 80;
    server_name <site_name.com>;
    return 301 https://<site_name.com>$request_uri;
}

    com

    server {
    listen 80;
    server_name mysite.com;
    return 301 https://mysite.com$request_uri;
}

    Also, em o nginx_ssl/nginx.conf file, change o servidor clause:

    server {
    listen 443 ssl;
    server_name <site_name.com>;
    ssl_certificate <certificate.crt>;
    ssl_certificate_key <certificate_key.key>;
    ...
}

    para

    server {
    listen 443 ssl;
    server_name mysite.com;
    ssl_certificate mycertificate.crt;
    ssl_certificate_key mycertificate_key.key;
    
    ...
}
  2. Add o certificate e key para o nginx_ssl directory: Then, you need para edit o nginx_ssl/Dockerfile adding o certificate nome.

    Replace

    COPY <certificate.crt> <certificate.crt>
COPY <certificate_key.key> <certificate_key.key>

    com

    COPY mycertificate.crt mycertificate.crt
COPY mycertificate_key.key mycertificate_key.key

Para finish, use o command Modo de produção com SSL described em subsection 2.2 Instruções de execução.
