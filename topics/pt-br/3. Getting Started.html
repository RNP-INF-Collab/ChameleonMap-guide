Primeiros passos

O follow articles describe o first steps para use o sistema, whether as um administrador ou as um end usuário. Para o administrador é necessary para get acesso para backend management sistema, providing um valid pair de usuário e senha. One time inside o sistema o admin pode add, remove ou edit information like described em o section "Visão geral da interface administrativa". AS para usuários, o step-by-step guide de o features de o sistema é proviede em section "Visão geral da interface do usuário".
