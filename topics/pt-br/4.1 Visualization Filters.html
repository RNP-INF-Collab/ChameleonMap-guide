Principais funcionalidades

Filtros de visualização

Em ChameleonMap, o menus de tags registered em o sistema são presented para o usuário em um side menu palette. Usuários pode interact com este palette para selecione um menu, making it o current menu. Once um menu é selected, o mapa displays o tags associated com it through colored markers.

Each registered local com um active tag é represented por um marker com o color de o respective tag. Locais com multiple active tags generate unique markers filled com um mosaic composed de o colors de all active tags present em que local.

O sistema's filtering mechanism empowers usuários para control o visibility de each tag em o current menu. Este real-time adjustment allows usuários para tailor o visual representation de information em o mapa. O visibility adjustment depends em both o selected current menu e o usuário's tag visibility settings.

Figure 4.1.0 illustrates o functionality de visibility adjustment. Em este example, o usuário has deactivated o visualization de two out de three tags em o current menu (Capacity), resulting em um partial view de locais associated com o tags.

O filtering mechanism extends para registered links, both directly e indirectly. Indirectly, links são visualized based em o currently active tags. Links irá ser drawn if both o origin e destination locais have drawn markers. Additionally, there é direct link filtering through o links menu, operating as um layer above o filtering. Este allows control over o display de links based em o current view state sem altering o current tag menu.
