Visão geral da interface administrativa

O first step para o administrador de o sistema é para get acesso em o backend management sistema. SInce already there é um installed e running instance de o Chameleon Mapa, o administration section pode ser accessed por o running instance url added por "/admin". Then, like em o image bellow, it deve ser provided um valid admin username e its senha. Por padrão one administrador usuário called admin e com senha admin é setted. Este padrão admin dados pode ser changed em instatiation, via code changing. Another way para change o padrão administration info é logging com it e change its senha.

One time inside o administrador sistema it é possible para criar novo administrador usuários e edit o sistema banco de dados. Para each element de o mapas sytem, which são Menus, Locais, Tags, Links e Links Groups, there é um two buttons, 'Add' e 'Change', which permit para add novo de este kind de element ou edit ou exclude o existents, respectevely. Otherwise there é um button Mapa Settings, which offer para o administradores o possiblity para configure e customize o mapa.
