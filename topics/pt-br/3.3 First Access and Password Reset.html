Primeiro acesso e redefinição de senha

Este section explains how usuários acesso ChameleonMap para o first time ou reset their senha when needed. Em ChameleonMap, both actions use o same process through o First Acesso ou Forgot Senha? option em o tenant login página.

Each usuário deve acesso ChameleonMap through o URL de o tenant para which they belong. O tenant URL é provided por o organization administrador e usually follows o domain configurado para que environment.

Importante: Use only o tenant URL provided por your administrador. Um usuário account é valid only inside o tenant where it foi criado.

Antes de começar

Make sure you have:

  • o tenant acesso URL;
  • o email address registered por o administrador;
  • acesso para o email inbox used during registration.

First Acesso ou Senha Reset

When um usuário é criado por um administrador, no senha é defined directly em o Administrative Portal. O usuário creates their senha using o same flow used para recover um existing senha.

Para criar ou reset your senha:

  1. Abra o tenant URL provided por your administrador.
  2. Clique First Acesso ou Forgot Senha?.
  3. Enter o email address registered para your account.
  4. Submit o request.
  5. Abra o email message sent por ChameleonMap.
  6. Follow o link em o email e define your senha.
  7. Return para o tenant login página.
  8. Log em using your email address e novo senha.

Solução de problemas

O email did not arrive

Check o spam ou junk folder. If o message é not disponível, confirm com o administrador que o registered email address é correct.

O reset link expired

Return para o login página e request um novo first acesso ou senha reset email.

O usuário still cannot log em

Ask o tenant administrador para verify que o usuário exists, belongs para o correct tenant, e é active.
