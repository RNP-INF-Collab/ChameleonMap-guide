Solução de problemas

Problemas comuns e soluções

  1. O sistema foi build apparently successfully, because I pode abra o admin página, but o usuário página does not abra:

    Este problem pode occur when all o containers de o sistema são builded successfully, unless o nginx container. You pode trying restart o nginx e o front-end containers.

  2. O sistema foi instantiated but any admin usuário foi automatically criar:

    Este problem pode happen when o django's admin-creation-module de o backend fails em o initialization. You pode solve easily este problem using o backend tools em command line. 
    python createadmin "name" "password"
