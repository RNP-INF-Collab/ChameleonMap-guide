Instruções de execução

  1. Set up o environment files:

    After pulling o code de o repository, copy o files

    • env/env_example.prod
    • env/env_example.dev

    para novo files

    • env/.env.prod
    • env/.env.dev

    e replace/insert valores para o keys listed below com your own.

    • SECRET_KEY - Pode ser any valor, deve ser random 
      python3 -c "import secrets; print(secrets.token_urlsafe(50))"
    • DJANGO_ALLOWED_HOSTS - O list de names para which este servidor irá respond (defaults sufficient para local/dev installations; add/replace para público acesso)
    • DJANGO_SUPERUSER_USERNAME - Um username para o admin usuário
    • DJANGO_SUPERUSER_PASSWORD - Um senha para o admin usuário
    • DJANGO_SUPERUSER_EMAIL - O email address para o admin usuário
    • SQL_DATABASE - O preferred nome de o criado banco de dados
    • SQL_USER - O username para o banco de dados
    • SQL_PASSWORD - O senha para o banco de dados

    If you want para use pgAdmin para acesso PostgreSQL, configure o following items (only em dev mode):
    • PGADMIN_DEFAULT_EMAIL
    • PGADMIN_DEFAULT_PASSWORD
    • PGADMIN_PORT

  2. Run o following command:
    • Modo de produção - docker-compose -f docker-compose.yml -f docker-compose.prod.yml -p map up --build
    • Modo de desenvolvimento - docker-compose -f docker-compose.yml -f docker-compose.dev.yml -p map up --build

      • Note: Before executing o below command, please refer para subsection 2.3, Configuração SSL, para important setup instructions.
    • Modo de produção com SSL - docker-compose -f docker-compose.yml -f docker-compose.prod.ssl.yml -p map up --build
