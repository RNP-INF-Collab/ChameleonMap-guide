2.1 Pré-requisitos

Before proceeding com o ChameleonMap installation, it é essential que you have Docker e Docker Compose installed em your sistema. Estes tools são indispensable para running ChameleonMap.

Instalando o Docker no Linux

  1. Update your sistema's package index:

    sudo apt-get update

  2. Install packages para allow apt para use um repository over HTTPS:

    sudo apt-get install apt-transport-https ca-certificates curl software-properties-common

  3. Add Docker's official GPG key:

    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -

  4. Add o Docker repository para APT sources:

    sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"

  5. Update o package index again after adding o Docker repository:

    sudo apt-get update

  6. Install Docker CE (Community Edition):

    sudo apt-get install docker-ce

  7. Verify que Docker foi installed correctly:

    sudo docker run hello-world

    If o installation foi successful, you irá see um message indicating que Docker é running correctly.


Installing Docker Compose em Linux

  1. Download o latest version de Docker Compose:

    sudo curl -L "https://github.com/docker/compose/releases/download/1.29.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

  2. Make o Docker Compose binary executable:

    sudo chmod +x /usr/local/bin/docker-compose

  3. Verify o installation:

    docker-compose --version

    Este deve display o version de Docker Compose, confirming que o installation foi successful.


After completing estes steps, your sistema irá ser ready para o ChameleonMap installation. Proceed para o next section para learn how para configure e start ChameleonMap.
