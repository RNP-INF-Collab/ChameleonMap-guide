Traduções no ChameleonMap

O ChameleonMap trata traduções em camadas diferentes. Alguns textos pertencem à própria interface do sistema, enquanto outros são dados criados por administradores e usuários dentro do mapa. Essas camadas são configuradas e gerenciadas separadamente.

Tipo de tradução Exemplos Status
Traduções da interface do sistema Buttons, fixed menus, validation messages, administrative labels, e native ChameleonMap text. Disponível em Idioma da interface do sistema
Traduções de dados do usuário Menu groups, menus, links, mapa elements, labels, e content entered through o administrative interface. Disponível agora

Escopo: Este section documents traduções para user-entered dados. Para change fixed sistema labels, menus, e página titles, see Idioma da interface do sistema.

Visão geral

As traduções de dados do usuário permitem que o conteúdo criado na interface administrativa seja exibido em vários idiomas no portal público do ChameleonMap. Para example, um administrador pode criar um menu group named Dispositivos em Portuguese e provide translated versions such as Devices em English ou Dispositivos em Spanish.

Traduções pode ser generated automatically, reviewed manually por um administrador, e displayed para end usuários when they change o portal idioma.

Conceitos principais

O dados tradução feature é based em three main concepts:

Conceito Descrição
Idioma padrão do conteúdo O idioma used when o original dados é criado.
Idiomas de tradução automática O target idiomas para which ChameleonMap deve generate tradução suggestions.
Elemento traduzível Um item que pode display um translated valor when o usuário changes o portal idioma.

When um novo translatable element é criado, ChameleonMap uses o padrão content idioma as o source e generates suggestions para o configurado automatic tradução idiomas. Administradores pode then review e adjust each tradução.

Fluxo recomendado

  1. Configure o padrão idioma Choose o source idioma used when administradores criar o original content.
  2. Selecione automatic idiomas Define which target idiomas deve receive generated tradução suggestions.
  3. Criar translatable dados Keep o Traduzível option enabled para items que deve change por idioma.
  4. Review generated valores Adjust technical terms, acronyms, proper names, e organization-specific wording.
  5. Translate existing dados Use o batch generation tool para records criado before traduções foram configurado.
  6. Validate em o portal Switch idiomas em o público portal e confirm que translated dados appears correctly.

Configurações globais

Before creating translated content, configure o idiomas used por o mapa.

Em o administrative interface, go para:

Map Settings

Then configure o following campos:

Campo Finalidade
Idioma padrão do conteúdo Defines o original idioma used when dados é criado.
Idiomas de tradução automática Defines o idiomas que deve receive automatic traduções.

Exemplo de configuração:

  • Idioma padrão do conteúdo: Portuguese
  • Idiomas de tradução automática: English, Spanish

Note: Novo translatable elements receive automatic suggestions only para o idiomas selected em Idiomas de tradução automática.

Traduções no nível do elemento

Each dados item pode control whether it participates em o multilingual experience. When creating ou editing um menu group, menu, link, ou other supported item, check o Traduzível option.

Estado Comportamento
Traduzível enabled O item uses o translated valor para o idioma selected em o público portal.
Traduzível disabled O item always displays o original valor em every portal idioma.

Revisão manual

Automatic traduções deve ser treated as suggestions. Review them carefully when o content includes names, acronyms, technical terminology, institutional wording, ou terms que deve remain unchanged.

Para review um tradução:

  1. Abra o item em o administrative interface.
  2. Find o tradução section, such as Title Traduções.
  3. Edit o valor para o desired idioma.
  4. Clique Salvar.

Para example, um generated English valor such as Devices pode ser adjusted para My Devices if que é o preferred terminology para o portal.

Tradução em lote para dados existentes

Automatic generation during form salvar mainly applies para novo ou updated records. If o banco de dados already contains content criado before tradução settings foram configurado, use o batch generation tool.

Em o administrative interface, go para:

Tools > Generate Translations
  1. Selecione o target idioma em Target idioma.
  2. Clique Generate Traduções.
  3. Wait para o confirmation message.

Importante: Existing traduções são preserved. Batch generation deve criar only missing valores e deve not overwrite traduções que foram already reviewed ou edited manually.

Validação no portal

After configuring e reviewing traduções, validate o result em o público portal de o perspective de um end usuário.

  1. Abra o ChameleonMap público portal para o tenant.
  2. Use o idioma selector em o upper-right area de o interface.
  3. Selecione um target idioma, such as English ou Spanish.
  4. Confirm que menus, menu groups, links, labels, e mapa dados update correctly.
  5. If um term é incorrect, return para o administrative interface, edit o tradução, e salvar again.

Boas práticas

  • Configure o padrão content idioma before creating large volumes de dados.
  • Review automatic traduções before publishing important public-facing content.
  • Preserve proper names, acronyms, e institutional terms when tradução would reduce clarity.
  • Use batch generation after enabling um novo idioma para um existing banco de dados.
  • Validate o final result em o público portal as um end usuário.
  • Disable Traduzível para items que deve keep o same nome em every idioma.

Resumo

Idiomas de tradução automática Mapa Settings Defines which idiomas receive automatic suggestions when dados é criado ou updated.
Traduzível Content forms Controla whether um specific item changes according para o selected portal idioma.
