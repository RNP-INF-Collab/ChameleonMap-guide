Perguntas frequentes

1) What operational sistema do I need para instatiate o ChameleonMap sistema?

You pode run o ChameleonMap sistema em any operation sistema, as long as it é capable para run docker e docker-compose application. However we recomend para use um linux-like OS.

2) Like um usuário, what web browser irá I need para acess um ChameleonMap instatiated mapa?

ChameleonMap foi projected para ser compatible com o main web browsers, such as Mozila Firefox, Google Chrome e Microsoft Internet Explorer. Support para other browsers é not currently guaranteedAt o moment o support para other browsers é not guaranteed, as their correct operation has not been tested. But it pode work.
