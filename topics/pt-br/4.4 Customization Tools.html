Ferramentas de personalização

ChameleonMap é completely customized. Em o section "Change Mapa Settings", em o admin página, there são um lot um parameters que pode ser modified por o sistema administrador:

1) Mapa Nome:

O nome de o mapa que appears em o web browser Tab title.

2) Mapa Style:

O admin pode choose between two styles, "Gray Scale", which é o padrão, e "Blue colored", where o water bodies são presented em blue light color.

3) Inherit Child Local:

When este campo é enabled, um tag que é parent de another tags irá inherit all locais de o children que foi not previously declared em o parent. If instead you want para manually declare o locais para all tags, we suggest para keep este campo disabled.

4) Cluster Close Tags:

When este campo é enabled, tags located very close para each other irá ser grouped em clusters. Este mechanism only causes visual effects, not affecting o sistema behavior.

5) Initials zoom, latitude e longitude:

O initial observation point em o mapa.

6) Link feature:

When este campo é enabled, o link feature irá ser displayed em o front-end.
