Introdução ao ChameleonMap

Requisitos do sistema

Requisitos do lado do servidor

  • Sistema operacional: ChameleonMap servidor é compatible com Linux distributions.
  • Docker Composer e Docker: It é demand para have Docker e Docker Composer installed em servidor machine para run o sistema containers.
  • Hardware: Um computer com um minimum de 32GB RAM e um dual-core processor é recommended para proper servidor service offering.

Requisitos do lado do usuário

  • Navegador web: Ensure you são using o latest version de um modern web browser such as Google Chrome, Mozilla Firefox, ou Safari.
  • Hardware: Um computer com um minimum de 4GB RAM e um dual-core processor é recommended para smooth user-side operation.
  • Conexão com a internet: Usuários deve have um stable internet connection para acesso e interact com ChameleonMap.

Por meeting estes sistema requirements, both em o servidor e usuário sides, you'll ser ready para harness o full potential de ChameleonMap e explore its diverse applications em various domains.
