Solución de problemas

Problemas comunes y soluciones

  1. El sistema fue build apparently successfully, because I puede abra el admin página, but el usuario página does not abra:

    Este problem puede occur when all el containers de el sistema son builded successfully, unless el nginx container. You puede trying restart el nginx y el front-end containers.

  2. El sistema fue instantiated but any admin usuario fue automatically crear:

    Este problem puede happen when el django's admin-creation-module de el backend fails en el initialization. You puede solve easily este problem using el backend tools en command line. 
    python createadmin "name" "password"
