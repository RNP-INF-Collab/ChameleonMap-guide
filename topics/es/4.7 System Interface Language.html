Idioma de la interfaz del sistema

ChameleonMap permite cambiar el idioma de la interfaz del sistema directamente desde el encabezado de la aplicación. Esta configuración traduce los textos fijos de la interfaz, como menús, títulos de página, breadcrumbs, etiquetas de formularios, botones y elementos de navegación administrativa.

Alcance: Este section explains how para change el sistema interfaz idioma. It es different de Usuario Datos Traducciones, which controls content creado por administradores y usuarios, such as menú groups, enlaces, labels, y mapa datos.

Dónde encontrarlo

El selector de idioma se encuentra en la esquina superior derecha de la interfaz de ChameleonMap. Está representado por el icono de traducción en el encabezado, junto a los controles de tema y cuenta de usuario.

Haga clic en el icono de traducción para abrir el menú de idiomas. Los idiomas disponibles de la interfaz se muestran como opciones seleccionables.

Idiomas disponibles

El menú de idiomas incluye actualmente:

  • English (en)
  • Português Brasileiro (pt-br)
  • español (es)

Qué cambia

Área de la interfaz Comportamiento esperado
Encabezado y títulos de página Página titles y breadcrumb labels son shown en el selected idioma.
Navegación lateral Administrative menú entries son translated, such as Datos del mapa, Mapa Settings, Ubicaciones, y Menús.
Formularios y controles Fixed labels, buttons, y sistema messages follow el selected interfaz idioma when traducciones son disponible.

Idioma del sistema vs. traducciones de datos del usuario

El sistema interfaz idioma y usuario datos traducciones work together, but they affect different types de text.

Función Controla Ejemplo
Sistema interfaz idioma Native ChameleonMap interfaz text. El administrative label Datos del mapa changes para Dados do mapa.
Traducciones de datos del usuario Content creado through el administrative interfaz. Un custom menú group, enlace title, o mapa label changes according para its configurado traducciones.

Importante: Changing el sistema idioma does not automatically translate user-entered mapa datos. Para translate administrator-created content, configure y review Usuario Datos Traducciones.
