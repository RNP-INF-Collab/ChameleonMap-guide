Traducciones en ChameleonMap

ChameleonMap gestiona las traducciones en diferentes capas. Algunos textos pertenecen a la propia interfaz del sistema, mientras que otros son datos creados por administradores y usuarios dentro del mapa. Estas capas se configuran y administran por separado.

Tipo de traducción Ejemplos Estado
Traducciones de la interfaz del sistema Buttons, fixed menús, validation messages, administrative labels, y native ChameleonMap text. Disponible en Idioma de la interfaz del sistema
Traducciones de datos del usuario Menú groups, menús, enlaces, mapa elements, labels, y content entered through el administrative interfaz. Disponible ahora

Alcance: Este section documents traducciones para user-entered datos. Para change fixed sistema labels, menús, y página titles, see Idioma de la interfaz del sistema.

Resumen

Las traducciones de datos del usuario permiten que el contenido creado en la interfaz administrativa se muestre en varios idiomas en el portal público de ChameleonMap. Para example, un administrador puede crear un menú group named Dispositivos en Portuguese y provide translated versions such as Devices en English o Dispositivos en Spanish.

Traducciones puede ser generated automatically, reviewed manually por un administrador, y displayed para end usuarios when they change el portal idioma.

Conceptos principales

El datos traducción feature es based en three main concepts:

Concepto Descripción
Idioma predeterminado del contenido El idioma used when el original datos es creado.
Idiomas de traducción automática El target idiomas para which ChameleonMap debe generate traducción suggestions.
Elemento traducible Un item que puede display un translated valor when el usuario changes el portal idioma.

When un nuevo translatable element es creado, ChameleonMap uses el predeterminado content idioma as el source y generates suggestions para el configurado automatic traducción idiomas. Administradores puede then review y adjust each traducción.

Flujo recomendado

  1. Configure el predeterminado idioma Choose el source idioma used when administradores crear el original content.
  2. Seleccione automatic idiomas Define which target idiomas debe receive generated traducción suggestions.
  3. Crear translatable datos Keep el Traducible option enabled para items que debe change por idioma.
  4. Review generated valores Adjust technical terms, acronyms, proper names, y organization-specific wording.
  5. Translate existing datos Use el batch generation tool para records creado before traducciones fueron configurado.
  6. Validate en el portal Switch idiomas en el público portal y confirm que translated datos appears correctly.

Configuración global

Before creating translated content, configure el idiomas used por el mapa.

En el administrative interfaz, go para:

Map Settings

Then configure el following campos:

Campo Propósito
Idioma predeterminado del contenido Defines el original idioma used when datos es creado.
Idiomas de traducción automática Defines el idiomas que debe receive automatic traducciones.

Configuración de ejemplo:

  • Idioma predeterminado del contenido: Portuguese
  • Idiomas de traducción automática: English, Spanish

Note: Nuevo translatable elements receive automatic suggestions only para el idiomas selected en Idiomas de traducción automática.

Traducciones a nivel de elemento

Each datos item puede control whether it participates en el multilingual experience. When creating o editing un menú group, menú, enlace, o other supported item, check el Traducible option.

Estado Comportamiento
Traducible enabled El item uses el translated valor para el idioma selected en el público portal.
Traducible disabled El item always displays el original valor en every portal idioma.

Revisión manual

Automatic traducciones debe ser treated as suggestions. Review them carefully when el content includes names, acronyms, technical terminology, institutional wording, o terms que debe remain unchanged.

Para review un traducción:

  1. Abra el item en el administrative interfaz.
  2. Find el traducción section, such as Title Traducciones.
  3. Edit el valor para el desired idioma.
  4. Haga clic Guardar.

Para example, un generated English valor such as Devices puede ser adjusted para My Devices if que es el preferred terminology para el portal.

Traducción por lotes para datos existentes

Automatic generation during form guardar mainly applies para nuevo o updated records. If el base de datos already contains content creado before traducción settings fueron configurado, use el batch generation tool.

En el administrative interfaz, go para:

Tools > Generate Translations
  1. Seleccione el target idioma en Target idioma.
  2. Haga clic Generate Traducciones.
  3. Wait para el confirmation message.

Importante: Existing traducciones son preserved. Batch generation debe crear only missing valores y debe not overwrite traducciones que fueron already reviewed o edited manually.

Validación en el portal

After configuring y reviewing traducciones, validate el result en el público portal de el perspective de un end usuario.

  1. Abra el ChameleonMap público portal para el tenant.
  2. Use el idioma selector en el upper-right area de el interfaz.
  3. Seleccione un target idioma, such as English o Spanish.
  4. Confirm que menús, menú groups, enlaces, labels, y mapa datos update correctly.
  5. If un term es incorrect, return para el administrative interfaz, edit el traducción, y guardar again.

Buenas prácticas

  • Configure el predeterminado content idioma before creating large volumes de datos.
  • Review automatic traducciones before publishing important public-facing content.
  • Preserve proper names, acronyms, y institutional terms when traducción would reduce clarity.
  • Use batch generation after enabling un nuevo idioma para un existing base de datos.
  • Validate el final result en el público portal as un end usuario.
  • Disable Traducible para items que debe keep el same nombre en every idioma.
