Preguntas frecuentes

1) What operational sistema do I need para instatiate el ChameleonMap sistema?

You puede run el ChameleonMap sistema en any operation sistema, as long as it es capable para run docker y docker-compose application. However we recomend para use un linux-like OS.

2) Like un usuario, what web browser será I need para acess un ChameleonMap instatiated mapa?

ChameleonMap fue projected para ser compatible con el main web browsers, such as Mozila Firefox, Google Chrome y Microsoft Internet Explorer. Support para other browsers es not currently guaranteedAt el moment el support para other browsers es not guaranteed, as their correct operation has not been tested. But it puede work.
