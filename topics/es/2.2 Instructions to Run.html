Instrucciones de ejecución

  1. Set up el environment files:

    After pulling el code de el repository, copy el files

    • env/env_example.prod
    • env/env_example.dev

    para nuevo files

    • env/.env.prod
    • env/.env.dev

    y replace/insert valores para el keys listed below con your own.

    • SECRET_KEY - Puede ser any valor, debe ser random 
      python3 -c "import secrets; print(secrets.token_urlsafe(50))"
    • DJANGO_ALLOWED_HOSTS - El list de names para which este servidor será respond (defaults sufficient para local/dev installations; add/replace para público acceso)
    • DJANGO_SUPERUSER_USERNAME - Un username para el admin usuario
    • DJANGO_SUPERUSER_PASSWORD - Un contraseña para el admin usuario
    • DJANGO_SUPERUSER_EMAIL - El email address para el admin usuario
    • SQL_DATABASE - El preferred nombre de el creado base de datos
    • SQL_USER - El username para el base de datos
    • SQL_PASSWORD - El contraseña para el base de datos

    If you want para use pgAdmin para acceso PostgreSQL, configure el following items (only en dev mode):
    • PGADMIN_DEFAULT_EMAIL
    • PGADMIN_DEFAULT_PASSWORD
    • PGADMIN_PORT

  2. Run el following command:
    • Modo de producción - docker-compose -f docker-compose.yml -f docker-compose.prod.yml -p map up --build
    • Modo de desarrollo - docker-compose -f docker-compose.yml -f docker-compose.dev.yml -p map up --build

      • Note: Before executing el below command, please refer para subsection 2.3, Configuración SSL, para important setup instructions.
    • Modo de producción con SSL - docker-compose -f docker-compose.yml -f docker-compose.prod.ssl.yml -p map up --build
