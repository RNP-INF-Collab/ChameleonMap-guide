Configuración SSL

Para apply SSL para el inventory mapa, it es necessary para modify some NGINX settings para adapt para your site.

  1. Change el site nombre en el nginx_ssl/nginx.conf file:

    Replace

    server {
    listen 80;
    server_name <site_name.com>;
    return 301 https://<site_name.com>$request_uri;
}

    con

    server {
    listen 80;
    server_name mysite.com;
    return 301 https://mysite.com$request_uri;
}

    Also, en el nginx_ssl/nginx.conf file, change el servidor clause:

    server {
    listen 443 ssl;
    server_name <site_name.com>;
    ssl_certificate <certificate.crt>;
    ssl_certificate_key <certificate_key.key>;
    ...
}

    para

    server {
    listen 443 ssl;
    server_name mysite.com;
    ssl_certificate mycertificate.crt;
    ssl_certificate_key mycertificate_key.key;
    
    ...
}
  2. Add el certificate y key para el nginx_ssl directory: Then, you need para edit el nginx_ssl/Dockerfile adding el certificate nombre.

    Replace

    COPY <certificate.crt> <certificate.crt>
COPY <certificate_key.key> <certificate_key.key>

    con

    COPY mycertificate.crt mycertificate.crt
COPY mycertificate_key.key mycertificate_key.key

Para finish, use el command Modo de producción con SSL described en subsection 2.2 Instrucciones de ejecución.
