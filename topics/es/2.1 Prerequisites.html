2.1 Requisitos previos

Before proceeding con el ChameleonMap installation, it es essential que you have Docker y Docker Compose installed en your sistema. Estos tools son indispensable para running ChameleonMap.

Instalación de Docker en Linux

  1. Update your sistema's package index:

    sudo apt-get update

  2. Install packages para allow apt para use un repository over HTTPS:

    sudo apt-get install apt-transport-https ca-certificates curl software-properties-common

  3. Add Docker's official GPG key:

    curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo apt-key add -

  4. Add el Docker repository para APT sources:

    sudo add-apt-repository "deb [arch=amd64] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable"

  5. Update el package index again after adding el Docker repository:

    sudo apt-get update

  6. Install Docker CE (Community Edition):

    sudo apt-get install docker-ce

  7. Verify que Docker fue installed correctly:

    sudo docker run hello-world

    If el installation fue successful, you será see un message indicating que Docker es running correctly.


Installing Docker Compose en Linux

  1. Download el latest version de Docker Compose:

    sudo curl -L "https://github.com/docker/compose/releases/download/1.29.2/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose

  2. Make el Docker Compose binary executable:

    sudo chmod +x /usr/local/bin/docker-compose

  3. Verify el installation:

    docker-compose --version

    Este debe display el version de Docker Compose, confirming que el installation fue successful.


After completing estos steps, your sistema será ser ready para el ChameleonMap installation. Proceed para el next section para learn how para configure y start ChameleonMap.
