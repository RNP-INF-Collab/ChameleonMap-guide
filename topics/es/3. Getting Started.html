Primeros pasos

El follow articles describe el first steps para use el sistema, whether as un administrador o as un end usuario. Para el administrador es necessary para get acceso para backend management sistema, providing un valid pair de usuario y contraseña. One time inside el sistema el admin puede add, remove o edit information like described en el section "Resumen de la interfaz administrativa". AS para usuarios, el step-by-step guide de el features de el sistema es proviede en section "Resumen de la interfaz de usuario".
