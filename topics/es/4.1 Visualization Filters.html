Funciones principales

Filtros de visualización

En ChameleonMap, el menús de etiquetas registered en el sistema son presented para el usuario en un side menú palette. Usuarios puede interact con este palette para seleccione un menú, making it el current menú. Once un menú es selected, el mapa displays el etiquetas associated con it through colored markers.

Each registered ubicación con un active etiqueta es represented por un marker con el color de el respective etiqueta. Ubicaciones con multiple active etiquetas generate unique markers filled con un mosaic composed de el colors de all active etiquetas present en que ubicación.

El sistema's filtering mechanism empowers usuarios para control el visibility de each etiqueta en el current menú. Este real-time adjustment allows usuarios para tailor el visual representation de information en el mapa. El visibility adjustment depends en both el selected current menú y el usuario's etiqueta visibility settings.

Figure 4.1.0 illustrates el functionality de visibility adjustment. En este example, el usuario has deactivated el visualization de two out de three etiquetas en el current menú (Capacity), resulting en un partial view de ubicaciones associated con el etiquetas.

El filtering mechanism extends para registered enlaces, both directly y indirectly. Indirectly, enlaces son visualized based en el currently active etiquetas. Enlaces será ser drawn if both el origin y destination ubicaciones have drawn markers. Additionally, there es direct enlace filtering through el enlaces menú, operating as un layer above el filtering. Este allows control over el display de enlaces based en el current view state sin altering el current etiqueta menú.
