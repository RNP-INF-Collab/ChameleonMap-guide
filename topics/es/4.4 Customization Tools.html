Herramientas de personalización

ChameleonMap es completely customized. En el section "Change Mapa Settings", en el admin página, there son un lot un parameters que puede ser modified por el sistema administrador:

1) Mapa Nombre:

El nombre de el mapa que appears en el web browser Tab title.

2) Mapa Style:

El admin puede choose between two styles, "Gray Scale", which es el predeterminado, y "Blue colored", where el water bodies son presented en blue light color.

3) Inherit Child Ubicación:

When este campo es enabled, un etiqueta que es parent de another etiquetas será inherit all ubicaciones de el children que fue not previously declared en el parent. If instead you want para manually declare el ubicaciones para all etiquetas, we suggest para keep este campo disabled.

4) Cluster Close Etiquetas:

When este campo es enabled, etiquetas located very close para each other será ser grouped en clusters. Este mechanism only causes visual effects, not affecting el sistema behavior.

5) Initials zoom, latitude y longitude:

El initial observation point en el mapa.

6) Enlace feature:

When este campo es enabled, el enlace feature será ser displayed en el front-end.
