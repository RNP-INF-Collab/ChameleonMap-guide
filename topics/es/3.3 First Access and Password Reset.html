Primeros pasos

Primer acceso y restablecimiento de contraseña

Este section explains how usuarios acceso ChameleonMap para el first time o reset their contraseña when needed. En ChameleonMap, both actions use el same process through el First Acceso o Forgot Contraseña? option en el tenant login página.

Each usuario debe acceso ChameleonMap through el URL de el tenant para which they belong. El tenant URL es provided por el organization administrador y usually follows el domain configurado para que environment.

Importante: Use only el tenant URL provided por your administrador. Un usuario account es valid only inside el tenant where it fue creado.

Antes de comenzar

Make sure you have:

  • el tenant acceso URL;
  • el email address registered por el administrador;
  • acceso para el email inbox used during registration.

First Acceso o Contraseña Reset

When un usuario es creado por un administrador, no contraseña es defined directly en el Administrative Portal. El usuario creates their contraseña using el same flow used para recover un existing contraseña.

Para crear o reset your contraseña:

  1. Abra el tenant URL provided por your administrador.
  2. Haga clic First Acceso o Forgot Contraseña?.
  3. Enter el email address registered para your account.
  4. Submit el request.
  5. Abra el email message sent por ChameleonMap.
  6. Follow el enlace en el email y define your contraseña.
  7. Return para el tenant login página.
  8. Log en using your email address y nuevo contraseña.

Solución de problemas

El email did not arrive

Check el spam o junk folder. If el message es not disponible, confirm con el administrador que el registered email address es correct.

El reset enlace expired

Return para el login página y request un nuevo first acceso o contraseña reset email.

El usuario still cannot log en

Ask el tenant administrador para verify que el usuario exists, belongs para el correct tenant, y es active.
