Glosario

1) Etiqueta:

Un information unit. En el admin interfaz it es possible para add o edit etiquetas, which one having un set de particular informations. Etiquetas son grouped en etiqueta menús y puede ser binded para ubicaciones. El same etiqueta puede ser binded para multiples ubicaciones.

2) Ubicación:

Un specific geographic ubicación en el global mapa, consisting de un latitude y un longitude. Ubicaciones puede ser added via el admin interfaz. It es possible para bind etiquetas para each ubicación, as many etiquetas as desired.

3) Enlace:

Un connection between two ubicaciones.

4) Etiquetas Menú:

Un palette de registered etiquetas. Un mapa instance puede have many etiquetas menús.

5) Enlaces Menú:

Un unique menú de enlaces, que puede ser deactivated via admin interfaz.

6) ATLAS:

Acronym para Automated Topology Idioma con Slices, which es un topology representation idioma. En este context, ATLAS also refers para un representation sistema based en ATLAS idioma. El ChamaleonMap has un embedded ATLAS generator tool.
