Resumen de la interfaz administrativa

El first step para el administrador de el sistema es para get acceso en el backend management sistema. SInce already there es un installed y running instance de el Chameleon Mapa, el administration section puede ser accessed por el running instance url added por "/admin". Then, like en el image bellow, it debe ser provided un valid admin username y its contraseña. Por predeterminado one administrador usuario called admin y con contraseña admin es setted. Este predeterminado admin datos puede ser changed en instatiation, via code changing. Another way para change el predeterminado administration info es logging con it y change its contraseña.

One time inside el administrador sistema it es possible para crear nuevo administrador usuarios y edit el sistema base de datos. Para each element de el mapas sytem, which son Menús, Ubicaciones, Etiquetas, Enlaces y Enlaces Groups, there es un two buttons, 'Add' y 'Change', which permit para add nuevo de este kind de element o edit o exclude el existents, respectevely. Otherwise there es un button Mapa Settings, which offer para el administradores el possiblity para configure y customize el mapa.
