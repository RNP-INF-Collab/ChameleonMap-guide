Niveles de información

En ChameleonMap, each registered element (etiqueta, ubicación, o enlace) puede have information assigned at different levels de detail: concise information y detailed information.

Información concisa: Este level es displayed en un simple popup de el element. El concise information provides un quick overview con spatial y operational limitations, making it ideal para presenting synthetic information.

Información detallada: Usuarios puede acceso detailed information en un expanded popup, offering greater representational power. Este expanded popup puede showcase texts, images, videos, y even incorporate external web páginas, making it un powerful tool para representing attributes y datos de un element.

Figure 4.2.0 illustrates el two levels de information assigned para un ubicación. En el left side, concise information es displayed within el simple popup. En el right side, el expanded popup shows detailed information, including un image, un table, y formatted text.

When el registered element es un etiqueta, there es un additional intermediate level de representation: el side popup.
